# HayDex / Hay-D

Make Hay Day trade lists, set prices, scan barn or shop photos, and share the result as text or an image. Photos, lists and settings stay on your device.

See the [user guide](GUIDE.md) for features and [model notes](MODEL.md) for scanner details.

Inspired by [Hay Day Image Generator](https://jjcuber.github.io/HayDayImageGeneratorSite/).
